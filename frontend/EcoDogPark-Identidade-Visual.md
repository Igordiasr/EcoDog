# Apresentação

## Sobre o projeto

Este documento estabelece as diretrizes visuais do projeto, reunindo os principais elementos que compõem sua identidade visual.

O objetivo é garantir que as interfaces, páginas, componentes e demais materiais desenvolvidos para o projeto mantenham uma comunicação visual consistente, reconhecível e coerente entre si.

Neste primeiro momento, a identidade visual é composta principalmente pela paleta de cores e pelo sistema tipográfico, que servirão como base para o desenvolvimento das interfaces e demais elementos gráficos.

## Objetivo da identidade visual

**A identidade visual deve proporcionar ao projeto**

- Consistência entre diferentes páginas e interfaces;

- Facilidade de reconhecimento visual;

- Hierarquia clara das informações;

- Personalidade própria;

- Padronização dos elementos desenvolvidos pela equipe;

Facilidade de aplicação em interfaces web e outros materiais digitais.

# Hierarquia da paleta

Para evitar que todas as cores tenham o mesmo peso visual, recomenda-se estabelecer uma hierarquia.

### Cores primárias

#247346
#45937F
#67B344

São responsáveis pela maior parte da identidade visual do projeto.

### Cor secundária

#ADD9CC

Utilizada principalmente para criar áreas de respiro e suporte visual.

### Cores de destaque

#DE8F3B
#F25835

Devem ser utilizadas para criar contraste e direcionar a atenção do usuário.

Uma proporção inicial que pode ser testada na interface é:

- 55% — #
/ fundos e áreas neutras
20% — #247346 / estrutura e elementos principais
10% — #45937F / elementos secundários e apoio
10% — #67B344 / ações e destaques
5% — #DE8F3B + #F25835 / assentos

Essa proporção não precisa ser rígida. Ela serve como ponto de partida para manter equilíbrio visual.

# Tipografia

A identidade tipográfica do projeto utiliza duas fontes principais além do padrão, “Roboto”:

**Fonte: Luckiest Guy**

**Fonte: Lilita One**

As duas possuem características marcantes e apresentam uma estética descontraída, expressiva e com forte presença visual.

Por isso, é importante estabelecer funções diferentes para cada uma, evitando que ambas sejam utilizadas indiscriminadamente.

## Luckiest Guy

Fonte: Luckiest Guy

A Luckiest Guy apresenta uma personalidade forte e informal, sendo adequada para elementos que precisam transmitir maior impacto visual.

**Aplicações sugeridas**

- Títulos principais;

- Nome de seções;

- Chamadas;

- Elementos promocionais;

- Frases de destaque;

- Títulos de páginas;

Elementos gráficos.

A fonte deve ser utilizada preferencialmente em tamanhos maiores junto de contorno, onde sua personalidade possa ser percebida sem comprometer a legibilidade.

## Lilita One

Fonte: Lilita One

A Lilita One possui uma aparência arredondada e amigável, podendo assumir uma função mais ampla dentro da interface.

**Aplicações sugeridas**

- Subtítulos;

- Títulos secundários;

- Botões;

- Cards;

- Menus;

- Categorias;

- Labels;

Elementos de interface.

# Direção visual

Com os elementos definidos até o momento, a identidade apresenta uma direção visual:

Divertida · Amigável · Energética · Colorida

A combinação dos verdes com laranja e vermelho cria uma identidade com bastante energia, enquanto as fontes arredondadas e expressivas reforçam uma estética mais descontraída.

A utilização dos elementos deve buscar equilíbrio entre personalidade e legibilidade, especialmente por se tratar de um projeto web.
